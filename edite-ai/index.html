Não. Os cortes, a legenda, as animações e os sons são feitos pela IA. Você só diz o que quer.

Funciona com os dois: no Claude pelo Claude Code e no ChatGPT pelo Codex. As aulas mostram a instalação de cada um.

Pode. É só escrever: "deixa mais rápido", "troca a cor da legenda", "tira os primeiros segundos". Ele refaz.

Não. É um projeto pronto para instalar e usar. As aulas são curtas e servem só para você instalar e editar o primeiro vídeo.
